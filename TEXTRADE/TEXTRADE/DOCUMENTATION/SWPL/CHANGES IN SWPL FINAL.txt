MASTERS
*************
1. DESIGNCARD TO BE ACTIVATED ON ITEMID
2. WHEN WE ENTER DETAILS IM DESIGN CARD WE WILL HAVE TO SAVE WARP AND WEFT IN ITEMMASTER, BUT NEED SHADE IN DESIGN CARD AND HAVE TO REMOVE DESIGN NO MANDATE IN DESIGN CARD
2. IN ITEMNAME THEY WILL PUNCH FACTORY ITEM NUMBER, AND IN DESIGN THEY WILL PUNCH OFFICE ITEM NUMBER, AS THEY WANT TO LINK FACTORY ITEMNAME AND OFFICE ITEMNAME
3. WE WILL ACTIVATE ITEMWISE DESIGN IN VERSION
4. AFTER THIS WE WILL HAVE TO SELECT ITEMNAME (FACTORY ITEM NAME) IN ITEM COLUMN AND DESIGN (OFFICE ITEMNAME) IN DESIGN COLUMN IN SALE ORDER AND ALL OTHER FORMS, AS WE WANT TO LINK BOTH THE ITEMNAMES
5. WE WILL ACTIVATE A FEATURE WHERE WE CAN ENTER DESIGN NUMBER AND ITEMNAME WILL COME AUTO SAME AS AVIS

YARN MODULE
***************
1. YARN PO MANDATORY
2. CHANGE LRNO TO BOXNO IN YARN INWARD
3. GIVE LRNO COLUMN IN YARN INWARD AGAINST TRANSPORT
4. GIVE A TEXTBOX OF HAMALI CHARGES IN YARN INWARD FORM, NO EFFECT ON ACCOUNTS
5. PARTYLOTNO AND OURLOTNO WILL BE SAME IN YARN INWARD
6. YARN STOCK WILL BE ADDED 
7. JOB ORDER ENTRY MANDATE, SHADE WISE, WITHOUT THIS NO PRODUCTION ENTRY WILL BE MADE, THIS JO NO WILL BE FETCHED EVERYWHERE
8. WITH RESPECT TO ITEM SELECTED IN JOB ORDER WE WILL FETCH THE WARP AND WEFT YARN FROM DESIGN CARD ALONG WITH WT, AND THIS WILL BE USED EVERYWHERE IN REPORTS
9. PR NO IS PARTY'S ORDER NUMBER WHICH WE GET WHEN WE TAKE ORDER FROM RELIANCE OR OTHER VENDOR, WE DO JOBWORK ALSO, THIS WILL BE MENTIONED IN JOBORDER FORM, THIS WILL BE USED IN NECESSARY FORMS
9. YARN STOCK WILL BE DEDUCTED WHEN WE ISSUE YARN TO JOBBER OR WARPER
10. WE WILL RECD BEAM FROM WARPER (IN HOUSE) OR OUTSIDE JOBBER AGAINST JOB ORDER MANDATORY
11. WHEN WE REC BEAM FROM WARPER, WE NEED GAMA NO NOT MANDATORY
12. CHECK BEAM RECD FROM WARPER SCREEN 
13. WE WILL NEED A UNIQUE BEAM NO (AUTO NO) 
14. WE NEED ROLL NUMBER (THIS ROLL NO IS MANDATORY) THIS IS FROM STORE STOCK OF ROLLS
15. ADD MTRS IN ROLLS RECD FORM, ALL BEAM STOCK WILL WORK ON THIS MTRS AND NOT CUT
16. GIVE SECTION OPTION IN ROLLS RECD MANDATORY
17. COLUMNS IN SCREEN (SRNO | DATE | ITEMNAME | PR NO | JOB NO | REED | REED SPACE | T.ENDS | T. MTRS | GAMA NO |
SECTION | ROLL NO (STORES) | YARN DETAILS | BEAM WT | BREAKAGE)
18. WE WILL GET THE REMAINING YARN IN RETURN FROM WEAVER OR JOBBER, CHECK BOTTOM RECD FROM WARPER SCREEN
19. THIS WILL BE ADDED IN YARN STOCK
20. THIS YARN CAN BE ISSUED ON OUR MACHINE FOR WINDING (IN HOUSE) OR JOBBER
21. AND WE CAN REC THE WINDED YARN FROM WINDING MACHINE OR JOBBER, REMAINING YARN WILL CAN BE CLEARED FROM WASTAGE OR LONGATION FORM
22. WHEN WE REC BEAM FROM JOBBER OR WARPER, BEAMSTOCK WILL BE POPULATED
23. THIS BEAM WILL BE ISSUED TO JOBBER, IF WE ARE SENDING OUTSIDE
24. BEAM STOCK WILL BE MAINTAINED WITH RESPECT TO MTRS (MTRS - OUTMTRS) > 0, WE ALREADY HAVE CUT, WE CAN USE THAT ALSO INSTEAD OF MTRS
25. WE WILL ISSUE BEAMS FOR 2 PROCESSES KNOTTING AND GETTING
26. WE WILL ISSUE BEAM TO JOBBER, IN CASE OF SWPL, THEY WILL ISSUE BEAM TO SELF JOBBER
27. WE WILL UPLOAD BEAMS ON EMPTY LOOMS, ONLY ISSUED BEAMS WILL BE ALLOWED TO BE UPLOADED
28. IN ALL THESE BEAM FORMS WE NEED ROLL NO (STORES)
29. WE NEED TO PUNCH LOOM EFFICIENCY REPORT DAILY (THIS IS A STAND ALONE FORM)
30. IN LOOM EFFICIENCY REPORT WE WILL SELECT LOOM NO AND WE WILL GET THE DESIGN NO AUTO, WE WILL PUNCH RPM, PICK, REC MTRS, WEFT BREAKAGE, WARP BREAKAGE, AND EFF % (CHECK THE SCREEN LOOM EFFICIENCY ENTRY)
31. WHEN WE PUNCH THE ABOVE DATA, WE WILL FETCH THE REPORT AUTO (CHECK THE LOOM EFFICIENCY REPORT)
32. WE WILL REC GREY FROM JOBBER
33. WE WILL NEED CONTRACTOR NAME AND SHIFT
34. WE WILL ISSUE WEFT TO THE WEAVER FROM YARN ISSUE ENTRY
35. GREY RECD FROM JOBBER, LOOM WISE
36. WHEN WE SELECT THE LOOM WE WILL GET BEAM NO AND OTHER DETAILS, WE WILL REC GREY MTRS AND SAVE THE ENTRY
37. BEAM BALANCE WILL BE WITH RESPECT TO MTRS NOT CUT, WE WILL GET ALL BEAMS WHERE (MTRS-BEMMTRS) > 0 AND WE NEED TO GIVE OPTION FOR BEAM CLOSE ALSO, IF CLOSED THEN BEAM WONT BE SHOWN IN GREY REC
38. GREY STOCK WILL BE POPULATED
39. GREY WILL BE SET TO DYEING (WE NEED TO ADD THIS ENTRY IN GREY ISSUE TO PROCESS)
40. WE WILL ENTER WT MANUALLY WHILE GREY REC, IF THERE IS DIFF IN WT FROM JOB ORDER AND GREY REC THEN INTIMATE, GIVE TOLERANCE OF GRAMS IN QUALITY, IF RECD WT IS GREATER OR LESS THEN THE TOLERANCE GRAMS THEN INTIMATE
41. THEN OUR NORMAL TEXTRADE WORK WILL BE EXECUTED
42. GIVE AN OPTION FOR ENTERING ASN IN CHALLAN AND INVOICE
